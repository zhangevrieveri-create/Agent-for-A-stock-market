# RL-Invest：融合新闻舆情与量价数据的强化学习智能投资系统

新浪财经个股新闻情绪、米筐 RQData 个股情绪指数与量价技术指标拼接为状态 S_t，经
**Bi-LSTM → Transformer 编码器 → 双重视角注意力** 提取特征，由 **PPO-Clip**
（课程噪声、自适应裁剪阈值、自适应学习率）学习 A 股投资组合的调仓权重。

## 数据

**米筐 RQData**：样本期为 2014-01-06 至 2025-10-29。全市场普通股（默认排除北交所）的前复权日线
包括开高低收、成交量、成交额、涨跌停价和换手率，另取沪深300作为基准。个股情绪指数通过
`get_factor` 获取，因子名填在 `rqdata.sentiment_factor`，以你账户的数据文档为准；不填时该特征置 0。

**新浪财经新闻**：按个股名称调用新浪搜索接口，同时抓取个股新闻列表页。两路结果按链接去重，并且
只保留标题中出现股票名称的新闻。首页请求失败的股票不会写文件，下次运行会重新爬取。

**【历史新闻导入位置】**：把历史新闻文件（csv 或 parquet）放进一个文件夹，在配置里设置
`news.history_dir: 路径`。步骤3 会把它们和爬取结果合并，再一起清洗。文件需包含 `datetime`、`title`
两列，再加 `order_book_id` 或 `name` 其中一列。读取逻辑在 `rlinvest/data/news_clean.py` 的
`load_history_news()`。

**防止未来信息**
- 15:00 之后以及非交易日发布的新闻，归入下一个交易日。
- 特征标准化只使用训练集的统计量。
- 在 t 日收盘按当日价格调仓，获得 t 到 t+1 的收益。

## 输入与输出

```
 米筐 RQData ──┐  量价/涨跌停/换手率/沪深300/情绪指数
 新浪财经新闻 ──┼─► 01~04 数据处理 ──► 状态张量 S ∈ R^{D×U×F} ──► 05 PPO 训练 ──► 策略网络 π_θ ──► 06 回测
 历史新闻(可选)─┘    清洗·情绪·指标                                      价值网络 V_φ
```

**模型（每个交易日 t 收盘时调用一次）**

| | 符号 | 形状 | 含义 |
|---|---|---|---|
| 输入 | s_t | 10 × 20 × 29 | 10 只股票 × 过去 T=20 个交易日 × 29 个特征（下表），已用训练集统计量标准化 |
| 输出 | μ_t | 11，取值 [0,1] | 策略均值：10 只股票 + 现金 |
| 输出 | σ_t | 11，取值 > 0 | 策略标准差，与 μ_t 组成高斯策略 N(μ_t, diag σ_t²) |
| 输出 | V(s_t) | 1 | 状态价值，只在训练时使用 |
| 动作 | A_t | 11，取值 [0,1]，和为 1 | 目标持仓权重。训练时从 N(μ_t, (σ_t+σ_noise)²) 采样后截断、归一化；回测时直接用 μ_t |

**环境**：输入 A_t。先施加交易约束（停牌、涨停不可买、跌停不可卖），在 t 日收盘调仓，扣除
τ·Σ|ΔA| 的交易成本。输出 t→t+1 的组合收益、奖励
r_t = w₁·短期收益 + w₂·差分夏普比率 − w₃·回撤惩罚，以及下一状态 s_{t+1}。

**各步骤文件**

| 步骤 | 输入 | 输出 |
|---|---|---|
| 01 | 米筐账号、配置 | 股票池、交易日、日线行情、沪深300、情绪指数 |
| 02 | 股票池 | 每只股票的新闻标题 csv |
| 03 | 新闻 csv（+ 历史新闻） | 清洗后新闻、标题情绪分、个股日度情绪、图1示例、表1 |
| 04 | 行情 + 日度情绪 + 情绪指数 | `u10.npz`：特征张量、价格、可买/可卖掩码、基准、日期与划分 |
| 05 | `u10.npz` | `best.pt`/`last.pt`、训练日志、表3、表4 |
| 06 | 模型 + `u10.npz` | 验证/测试集指标表、净值、每日持仓、净值图、持仓图、训练曲线 |

## 特征（F = 29）

| 类别 | 特征 | 进入模型的形式 |
|---|---|---|
| 基础量价 | 开盘、收盘、最高、最低、成交量、换手率 | 开/高/低相对收盘的偏离；收盘取对数收益；成交量取相对 20 日均量的对数 |
| 趋势指标 | MA5/10/30/120、EMA30、布林带上下轨 | 相对收盘价的偏离 |
| 波动指标 | ATR、ADX | ATR/收盘价，ADX/100 |
| 超买超卖 | KDJ-K/D/J、RSI6/12/24、CCI | 缩放到 0 附近 |
| 动量 | MACD（DIF/DEA/柱）、MTM | MACD/收盘价 |
| 舆情 | 新浪标题情绪、新闻条数、米筐情绪指数 | 无新闻日情绪按 0.8 衰减；条数取 log1p |

## 与论文的对齐

**表3 参数量完全复现**。`05_train.py` 会输出 `table3_params.csv`，总参数量为 **1,483,671**，各子模块数量与论文一致：

| 模块 | 参数量 | 由此确定的结构 |
|---|---|---|
| 前向/后向 LSTM | 81,408 ×2 | 输入 F=29，隐藏层 128 |
| Transformer 层（×2） | 330,112 | d=256，8 头，前馈维度 128 |
| 特征注意力、标的注意力 | 263,168 ×2 | d=256，8 头 |
| 策略网络 | 65,664 + 1,419 + 1,419 | 512→128→11（U=10 只股票 + 现金） |
| 价值网络 | 65,664 + 129 | 512→128→1 |

表3 只统计了一份特征提取模块，说明策略网络和价值网络共享编码器，本项目也按共享实现。BatchNorm
不带可训练参数，所以不计入表3。

**表4 超参数**全部按论文取值：η=3e-4，γ=0.99，λ=0.95，ε=0.2，σ₀=0.4，β=0.004，w₁/w₂/w₃=0.4/0.5/0.1，
τ=0.0018，r_f=0.01。

**算法1** 的对应实现：
- 采样缓存区容量 C=1000。
- 当 |D| ≥ B 时，进行 E 轮更新，每轮从 D 中采样 B 条。
- 旧策略概率用缓存中保存的 μ_i、σ_i 计算。
- 价值目标 V^target = M̂ + V_old(s)。
- 总损失 L_total = L_policy + 0.5·L_value。
- 每 100 步调整一次 ε_t = 0.2·(1 + 0.5·σ_t/σ_{t,old_W}) 与 η_t = η₀·exp(−α·ΔL/L)。

**论文没有给出、由本项目设定的参数**（在 `default.yaml` 中标注为 `[未给出]`）：

| 参数 | 取值 | 说明 |
|---|---|---|
| T | 20 | 历史窗口长度 |
| B / E | 256 / 10 | 轨迹批量、每批更新轮数 |
| update_interval | 100 | 每 100 步检查一次是否更新 |
| K | 200,000 | 训练总步数，GPU 上约 45 分钟 |
| α | 0.1 | 自适应学习率衰减系数 |
| 波动率窗口 / W | 20 / 60 | 当前波动率 σ_t 与历史平均波动率的窗口 |
| 数据划分 | 训练 2014–2021 / 验证 2022 / 测试 2023–2025.10 | 按验证集夏普比率保存最优模型 |

**训练稳定性处理**（`rlinvest/rl/ppo.py`，均可在 `configs/default.yaml` 的 `rl` 段关闭）

| 问题（按算法1字面实现时的诊断） | 处理 |
|---|---|
| 价值损失约为策略损失的 200 倍，共享编码器的梯度被价值网络主导 | `reward_norm`：奖励按折扣回报的滑动标准差缩放 |
| GAE 使用采样时的旧价值估计，缓存区最旧样本已过期 10 轮更新 | 每轮更新开始时重算缓存区的 V(s)、V(s′) |
| 裁剪中心是采样时的行为策略，50%~70% 的样本被裁剪、梯度为 0 | `clip_center: current`：以本轮更新前的策略 π_k 为裁剪中心，用截断重要性权重 π_k/π_b 修正（GePPO） |
| 单轮更新 KL 达 0.2~0.8 | `target_kl`：KL(π_k‖π_θ) 超过阈值时停止本轮剩余的更新 |
| 初始 σ≈0.7（权重空间为 [0,1]），动作大面积截断，换手极高 | `sigma_init`：初始 σ=0.1，输出层小增益初始化，使初始策略近似等权 |
| 自适应学习率的 ΔL/L 由单轮损失计算，L≈0 时剧烈跳动 | 对策略损失取指数滑动平均后再代入公式 |
| 全局池化后的策略头难以区分不同标的 | `head: asset`：W_a2 的第 u 行只作用于第 u 只标的的表示，参数量与表3相同 |
| 缓存区旧样本在 π_k 下 log 概率低至 −500，概率比溢出为 inf，与下溢为 0 的权重相乘得 NaN，训练中途崩溃 | log 概率比截断到 [−20, 20]；非有限损失跳过并记录警告 |
| 动作截断到 [0,1] 后 σ 无约束增大（训练中涨到 1.5~2.8），μ 的梯度随 1/σ² 消失 | `sigma_max`：σ_max·tanh(σ/σ_max) 平滑上限，默认 0.3 |
| sigmoid 无法输出 0，压低权重会把 logit 推向 −∞，250 步内全部饱和、策略冻结 | `logit_l2`：μ 的 logit 加 L2 约束，默认 0.01 |
| 奖励以市场共同涨跌为主，调仓带来的差异被淹没 | `ret_baseline: equal_weight`：短期收益减去等权组合收益（外生控制变量，不改变最优策略） |
| KL 早停用 mean(logp_k − lp)，有正有负、噪声大 | 改用按重要性权重加权的非负估计 E[(r−1) − log r] |
| 用全样本期的新闻数选股，米筐情绪当日使用 | 只用训练期新闻数选股；米筐情绪滞后 1 个交易日 |

**训练可学习性检验**（在已知信号的合成数据上做的诊断，不在仓库中）
- 合成数据：情绪为 AR(1) 过程，对次日收益有 0.3%×s 的预测力。按信号倾斜的预言机组合，测试集年化 62%，等权为 24%。
- 改动前的代码：验证集夏普一直在 −0.6~−0.8，最优模型是第 20 轮更新的初始策略，等于没学到东西。
- 用精确梯度直接训练同一网络（不经过强化学习），没有 logit 约束时 250 步内 μ 全部饱和，秩相关固定在 −0.10；
  加上 `logit_l2=0.01` 后秩相关达到 0.55~0.60。说明 sigmoid 饱和是网络学不到信号的主要原因。
- 强化学习加上 logit 约束后，验证集夏普的峰值从 0.56 提高到 0.85。但之后仍会回落，说明模型会过拟合训练期，
  必须依靠验证集选模型（`best.pt`）。`head: shared`（EIIE 式共享评估器）和 `weight_decay` 作为可选项保留。

**消融与重复实验**

**消融与重复实验**
- `rl.dual_attention: feature | asset | none`：关闭双重注意力中的分支。
- `rl.head: global | shared`：对比不同的策略输出头。
- `dataset.sentiment: []`：去掉舆情特征。
- `rl.sigma0: 0`：去掉课程噪声。
- `rl.eps_bounds: [0.2, 0.2]`：固定裁剪参数。
- `rl.alpha: 0`：固定学习率。
- 多种子重复实验：

```bash
for s in 1 2 3 4 5; do
  python scripts/05_train.py --seed $s --tag seed$s && python scripts/06_backtest.py --tag seed$s
done
```

**实现上的几处说明**
- **课程噪声**：σ_noise = σ₀·exp(−β·n)，n 为已完成的更新轮次。如果按每个交易步衰减，β=0.004 时
  约 1000 步后噪声就接近 0，课程学习起不到作用，所以按更新轮次衰减。
- **逐标的策略头**：论文写 h^global = (1/T)Σ_t C_t，C_t 的形状是 U×T×512，只对时间求平均时得到
  的其实是逐标的的 U×512 表示。策略网络在逐标的表示上计算：μ_u = sigmoid(W_a2[u]·GELU(W_a1 h_u))；
  现金和价值网络使用对标的再求平均后的 512 维 h^global。参数量与表3完全一致。另外在 Bi-LSTM 之后
  加了固定的正弦标的位置编码，没有可训练参数，让标的注意力能区分不同股票。
- **ε_t 的取值**：按论文公式，波动率比值为 1 时 ε_t=0.3，并不等于初始值 0.2。程序把 ε_t 限制在
  [0.1, 0.4]，把 η_t 限制在 [3e-5, 1e-3]。
- **A 股交易约束**：停牌不可交易，涨停不可买入，跌停不可卖出。受限部分保持原持仓。配置项
  `rl.trade_limits` 可以关闭这些约束。
